# Token Monitor Android 1.8.0

- 会话详情新增「对话与上下文」，仅适配 Antigravity 和 ChatGPT Codex。点击查看时，从选定的在线来源设备按需查询，不将正文加入日常采集或 Hub 持久化。
- 支持用户提问、助手回复、折叠的工具 / 上下文记录、复制、刷新和长对话分页；长消息续文保留原文。
- 多个设备持有同一会话时可切换来源；设备离线、未开启、旧 Hub、缺少日志和超时分别提示。
- 正文经原生认证 GET 读取并按纯文本显示。切换会话 / 来源 / Hub、返回或进入后台会清空当前正文并拒绝旧响应；不改变 Keystore、WebView 网络限制、通知与微件边界。

需要支持本功能的 [AoXIUy/token-monitor](https://github.com/AoXIUy/token-monitor) Node Hub 与常驻来源端，两端分别启用 `TOKEN_MONITOR_SESSION_CONVERSATIONS=1`。Cloudflare Worker 和一次性 Agent 暂不支持。Antigravity 需要本机导出日志；Codex 需要保留 rollout。详见[使用和部署说明](../SESSION_CONVERSATIONS.md)。

本版本沿用原正式签名，versionCode 为 19。没有新增依赖或构建工具。发布工作流仍需通过便携校验、Android lint、真实模拟器仪器测试及正式 APK 身份、证书和对齐校验。
