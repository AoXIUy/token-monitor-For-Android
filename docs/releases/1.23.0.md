# Token Monitor Android 1.23.0

- 同步适配 [Javis603/token-monitor v0.95.1](https://github.com/Javis603/token-monitor/releases/tag/v0.95.1) 与 [v0.96.0](https://github.com/Javis603/token-monitor/releases/tag/v0.96.0)（`39606ac3`）全部与只读客户端相关的前端及原生能力：
  - **Notion AI 个人积分池：** 增量同步 `src/shared/limits/windowText.js`，支持 Notion AI `Standard` 与 `Select` 计费点数窗口的原始计数明细展示，并扩展原生桌面微件标签白名单（`WidgetLayoutPolicy.java`）。
  - **Devin 登录邮箱优先展示：** 更新总览脉冲与额度界面（`OverviewView.tsx` / `LimitsView.tsx`），未设置自定义显示名称时优先展示匹配登录邮箱（缺失时回退组织名），并在详情中避免邮箱重复显示、保留组织名作为次级元信息。
  - **Qoder 与 Z.ai Team 跨设备隔离：** 在 `model.js` 与 `LimitsHistoryStore.java` 中为 Qoder 站点附加中文区域标识（国际站 / 中国站）及便携别名标记（`accountKeyPortable`），隔离尚未绑定账号的迁移默认槽位避免误触发别名历史合并；兼容 Z.ai Team 多项目分组隔离。
  - **Antigravity 分组顺序与旧版无读数池处理：** `model.js` 对齐 Antigravity 额度窗口分组顺序（支持新增服务组别及已禁用保留窗口），并隐藏无可用百分比读数的旧版无读数池。
  - **每日趋势严格日历校验与等宽描边：** `model.js` 的 `daily(stats)` 增加严格 UTC 公历日历日期校验，保持“缺失日期不补零”策略；`HistoryChart.tsx` 为趋势主折线启用 `vectorEffect="non-scaling-stroke"`，使宽屏下线条粗细保持一致。
  - **回归测试与文档更新：** 更新 `docs/UPSTREAM.md`、`docs/DEVELOPMENT.md` 与 `docs/upstream-files.json`，新增 `tests/android/upstream96.test.js`，并扩充 `tests/android/WidgetPolicyChecks.java` 与 `LimitsHistoryStoreTest.java` 验证。

本版沿用原正式签名，`versionCode` 为 `42`。没有新增依赖、权限或构建工具。
