# Token Monitor Android 1.15.2

- 修复 1.15.0 引入的后台完成提醒回归：读取 Hub 响应后再校验会话时间，避免将请求期间生成的新活动误判为未来数据，恢复活动基线及随后明确结束事件的通知。
- 加强 Android 15 仪器回归：延迟响应后生成活动记录，并重复返回同一个结束事件，验证后台通知、单次去重和点击跳转；WebView 操作回调沿用页面就绪的 20 秒等待预算，减少较慢模拟器上的页面切换超时。
- 包含 1.15.0 的 Codex / Antigravity 只读审批提醒及 1.15.1 的通知异步投递测试修复，审批操作仍需在电脑端完成。

本版本沿用原正式签名，versionCode 为 30。没有新增依赖、系统权限或 Hub 接口。正式发布需通过便携校验、Android lint、模拟器仪器测试及 APK 身份、证书和 ZIP 对齐校验。
