# Token Monitor Android 1.12.0

- Antigravity / Codex 会话的“性能与上下文”增加实时输出 tok/s、tok/min 和最近五分钟速率趋势。
- 使用来源设备的真实输出计数增量与来源采样时间差；tok/min 是同一间隔的分钟折算。原有累计匹配速度明确标为“历史匹配均速（非实时）”，不会作为新读数的替代。
- 多设备副本分别观测，可选择来源。重复、迟到、过期快照不补造点；离线留空，切换设备、计数重置及后台恢复后重新建立基线。
- 打开详情后开始积累趋势；只在回复结束时写入的用量日志形成批量观测，不表示逐 Token 流速。没有新读数时保持等待或不可用。

共享计算规则与桌面 0.92.0 一致，沿用现有原生统计通道；没有新增依赖、Hub 网络接口、权限或构建工具。CC Switch 参考及完整口径见[功能说明](https://github.com/AoXIUy/token-monitor/blob/v0.92.0/docs/session-realtime.md)。

本版本沿用原正式签名，versionCode 为 23。正式发布需通过便携校验、Android lint、模拟器仪器测试，以及 APK 身份、证书和 ZIP 对齐校验。
