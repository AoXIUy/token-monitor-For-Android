# Token Monitor Android 1.19.0

- 适配主 Hub `0.97.0` **第三方 AI API 智能分析**、**OpenClaw 微信接入状态** 与 **第三方 AI API 余额快照**（严格只读）：
  - **第三方 AI 智能分析卡片**：在日报 / 周报 / 月报详情页展示主 Hub 缓存的第三方 AI API（OpenAI 兼容 / Anthropic Messages）分析总结，支持模型/服务商标识、数据更新（`stale`）提示与一键复制 AI 分析内容。
  - **OpenClaw 微信通道状态条**：当主 Hub 开启 OpenClaw 微信推送时，在报告页展示推送通道（如 `openclaw-weixin`）、周期自动推送状态与最近推送结果。
  - **第三方 API 与余额快照**：在报告详情页内联展示 `thirdparty`（New API / Sub2API / Custom）及带余额账户的剩余额度、今日消耗与本月消耗。
  - **只读边界保持不变**：仅通过既有受鉴权的只读 `GET /api/reports` 与 `GET /api/reports/:granularity/:periodKey?format=both` 读取脱敏元信息，不在客户端存储任何第三方 AI Key 或 OpenClaw Hook Token。

本版沿用原正式签名，`versionCode` 为 `37`。没有新增依赖、权限或构建工具。
