# Token Monitor Android 1.16.0

- 总览「用量分布」新增「设备」标签，按「工具 · 设备 · 模型 · 项目」顺序展示全部设备视图下的多设备分布；已筛选单台设备时自动隐藏该标签并切回「工具」。
- 每条设备分布保留设备图标、在线/状态指示与唯一设备 ID 区分，支持按 Token / 费用排序与设备名、ID、系统关键词搜索；可展开查看该设备的工具构成与未归因余量，也可直接点击「筛选」切换到单台设备。
- 周期已结束与暂无读数的设备保留在列表底部并标注 `—` 与状态标签，不计入有效占比且不与真实零用量混淆；上方「设备用量贡献」快捷卡片新增跳转入口直达完整设备分布。

本版沿用原正式签名，`versionCode` 为 `32`。没有新增依赖、权限或构建工具。
