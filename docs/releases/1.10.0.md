# Token Monitor Android 1.10.0

- 总览新增会话、额度与设备贡献速览，可进入会话详情、额度页或筛选单台设备；会话状态沿用来源、前台和数据新鲜度校验。
- 用量组成及输入缓存命中率集中展示；未定价用量仍提示已知费用小计，缺失或过期的设备周期保持不可用，真实零用量保留为零。
- 历史趋势曲线、每日柱体和数值明细共享日期选择，支持每日 / 区间累计切换，并显示有记录日期的日均与合计。
- 工具、模型及项目分布新增关键词筛选、Token / 费用排序与展开全部，工具条目可直接查看该工具的会话。

补充设备速览的缺失、过期、真实零值及下钻回归；页面就绪仪器测试的回调等待统一使用原有 20 秒总期限。

本版本沿用原正式签名，versionCode 为 21。没有新增依赖、网络接口、权限或构建工具。正式发布需通过便携校验、Android lint、模拟器仪器测试及 APK 身份、证书和 ZIP 对齐校验。
