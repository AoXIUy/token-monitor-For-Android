# Token Monitor Android 1.9.0

- 对话默认展示用户提问和助手回复，连续的工具、上下文及日志中的思考摘要聚合为事件详情，可逐组查看或统一显示。
- 支持搜索已加载的对话与事件，同一条长消息的相邻续文自动合并，复制时保留原文。
- 会话列表新增最近、用量和费用排序，以及无需展开用量速览的「对话与详情」快捷入口。
- 会话页的完成提醒设置改为紧凑展示，可展开查看测试通知、系统设置及后台运行说明。

在线正文仍仅支持 Antigravity 和 ChatGPT Codex，需要支持此功能的 Node Hub 和常驻来源端，配置见[在线会话说明](../SESSION_CONVERSATIONS.md)。正文按需读取，仅用于当前查看；本次不新增网络接口或权限。

本版本沿用原正式签名，versionCode 为 20。没有新增依赖或构建工具。发布工作流需通过便携校验、Android lint、模拟器仪器测试及正式 APK 身份、证书和 ZIP 对齐校验。
