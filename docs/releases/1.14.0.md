# Token Monitor Android 1.14.0

- 将筛选栏的原生系统 `<select>` 设备选择器升级为深色玻璃态设备选择弹窗（`DevicePickerDialog`），移动端适配底部抽屉弹出，宽屏居中展示。
- 弹窗内支持展示设备硬件图标、在线/过期状态、OS 与 Agent 版本、当前统计周期的 Token/费用或额度账户汇总；超过 4 台设备时自动提供搜索过滤，并提供已移除设备提示与「全部设备详细状态」快捷跳转。
- 支持通过物理/手势返回键（`handleBackNavigation`）、Esc 键或遮罩点击关闭弹窗，并保留隐藏原生选择器同步以维持兼容性。

本版本沿用原正式签名，versionCode 为 26。没有新增 npm/Gradle 依赖、Hub 网络接口或系统权限。正式发布需通过便携校验、Android lint、模拟器仪器测试及 APK 身份、证书和 ZIP 对齐校验。
