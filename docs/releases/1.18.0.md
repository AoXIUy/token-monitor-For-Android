# Token Monitor Android 1.18.0

- 适配主 Hub `0.96.0` **按天 / 按周 / 按月数据使用与项目分析报告**功能（严格只读）：
  - **分析报告视图**：从「用量总览」卡片直接进入日报 / 周报 / 月报分析页，支持当期实时与主 Hub 历史归档期次切换，直观查看总览指标、上期环比对比、关键特征信号、项目消耗排行（含主力工具与模型）、工具与模型效率、逐日趋势及多设备贡献。
  - **标准 Markdown 原文与一键复制**：支持在结构化视图与标准 `token-monitor-report/v1` Markdown 原文之间切换，并支持一键复制全文用于 AI MCP 工具或笔记分析。
  - **只读原生边界**：`ConnectionSpec` 严格限制报告请求为只读 `GET`（`/api/reports` 与 `/api/reports/:granularity/:periodKey?format=both`），由双有界队列隔离列表与详情请求并在切换连接或切入后台时自动取消与清除旧缓存。

本版沿用原正式签名，`versionCode` 为 `36`。没有新增依赖、权限或构建工具。
