# Token Monitor Android 1.14.1

- 修复「会话与状态」页切换「累计」统计周期时的 React Hook 顺序异常崩溃，并新增顶层渲染错误兜底卡片（`ErrorBoundary`），避免界面白屏。
- 通过原生 `SharedPreferences` 白名单桥接持久化「额度与订阅」页的隐藏与显示口径偏好（对隐藏账户键做 SHA-256 摘要，不存明文邮箱或账户名），解决 WebView 禁用 DOM Storage 导致设置重启丢失的问题。
- 优化设备选择弹窗与在线会话正文状态边界：收到通知跳转或切页时同步关闭设备选择器，短暂轮询抖动时保留已读取的对话正文，并为复制提示补充自动复位。
- 改进移动端软键盘（IME）适配、系统字体缩放布局与无障碍交互：文本输入聚焦时隐藏底部导航避免遮挡操作区，补充搜索框与 SVG 趋势节点无障碍属性并扩大隐藏按钮触控区域。

本版本沿用原正式签名，versionCode 为 27。没有新增 npm/Gradle 依赖、Hub 网络接口或系统权限。正式发布需通过便携校验、Android lint、模拟器仪器测试及 APK 身份、证书和 ZIP 对齐校验。
