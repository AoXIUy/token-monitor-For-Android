# Token Monitor Android 1.24.2

- **修复 Android WebView 剪贴板复制失败：**
  - 在 `MainActivity` 原生桥接层新增只写且有长度上限（256K 字符）的 `copyText` 接口，通过系统 `ClipboardManager` 写入剪贴板；`copyTextToClipboard` 优先调用原生桥接并保留浏览器预览降级路径，修复 AG 账号池“复制邮箱”及全局 `CopyButton` 在 Android 15 WebView 中复制失败的问题。
- **修复 AG 账号池前后台生命周期与专属配额组分类边界：**
  - 在 `App.tsx` 中将 `foreground` 纳入 `AG 账号池` 查询副作用，应用从后台切回前台时自动重新拉取最新快照，避免非前台进入时卡在加载状态。
  - 修复 `agManagerState.js` 中仅含专属代号组（如 `Hydrogen`）或存在多个 Claude / 3P 分组时被错误归入半宽 `Gemini` 槽位的问题，保持整行展示与完整标题。
- **补充回归测试覆盖：**
  - 扩充 `tests/android/ag-manager-state.test.js` 便携式单测，并在 `StartupTest.java` 中新增 AG 账号池端到端 WebView / 原生桥接仪器回归测试（覆盖鉴权只读请求、卡片渲染、剪贴板实写、筛选搜索、前后台恢复及 404 / 401 / 超 512 KiB 降级）。

本版沿用原正式签名，`versionCode` 为 `45`。没有新增依赖、权限或构建工具。
