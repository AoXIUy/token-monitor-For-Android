# Token Monitor Android 1.20.0

- 重构 **报告专区（Reports Zone）**、新增独立 **报告窗口（Report Reading Window）**，并引入原生安全 GFM Markdown 排版引擎（严格只读）：
  - **报告专区改版与快捷入口**：顶部标题栏新增「报告」快捷按钮，总览页「报告专区 · AI 智能分析」卡片支持直接进入日报 / 周报 / 月报或直达报告窗口；报告页重构操作栏、周期与期次切换，并支持结构化概览与 Markdown 排版 / 源码视图切换。
  - **独立报告阅读窗口**：新增沉浸式模态阅读窗口，内置「AI 分析 / 完整排版 / Markdown 源码」三标签切换、标准 / 大字两档字号调节、一级/二级标题快捷目录跳转与一键复制；集成系统返回键处理，优先关闭阅读窗口再返回总览。
  - **原生安全 React GFM Markdown 渲染**：零外部依赖纯 React 排版渲染 AI 智能分析与完整分析报告，支持多级标题、粗体 / 斜体 / 删除线、嵌套列表与任务清单、引用块、代码块、可横向滚动的深色毛玻璃表格与 YAML Frontmatter 元信息卡片；全程禁用 `dangerouslySetInnerHTML` 且不触发外部网络加载，原始 HTML 标签以字面文本安全呈现。
  - **上游字段对齐与跨周期状态隔离**：规范化报告 `signals[]` 字段解析（兼容 `projectLabel` / `projectKey` 与各类百分比指标），并修复从不同粒度（如周报切入日报）进入报告页或报告窗口时残留旧期次详情的状态串扰。
  - **验证与只读边界**：扩充 `StartupTest` 仪器测试与前端 Markdown / 报告状态单测，验证入口布局、Markdown 安全边界、报告窗口切换与返回导航；只读 `GET` 接口与 Bearer 鉴权约束保持不变。

本版沿用原正式签名，`versionCode` 为 `38`。没有新增依赖、权限或构建工具。
