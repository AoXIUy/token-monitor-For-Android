# Token Monitor Android 1.24.0

- **Antigravity 账号池只读视图（AG 账号池）：**
  - 在「额度」页新增 **「AG 账号池」** 分段视图（`AntigravityManagerView.tsx`），通过 `GET /api/antigravity-manager`（响应上限 512 KiB）只读展示桌面端同步的多账号模型额度、各客户端当前激活标记（Classic / IDE / AGY / ACP）、异常状态（封禁 / 待验证 / 已停用）、自动刷新开关状态与时间戳。
  - 原生层（`ConnectionSpec.java`、`HubClient.java`、`MainActivity.java`）新增独立有界单线程队列 `agManagerNetwork`，支持请求代次隔离、切换或退出时取消在途请求，并在旧版 Hub 返回 HTTP 404 时友好降级提示；不包含任何凭据传输或写操作。
  - 新增 `ui/src/agManagerState.js`、`tests/android/ag-manager-state.test.js`、`ConnectionSpecChecks.java` 断言及 `docs/DEVELOPMENT.md` 文档更新。

本版沿用原正式签名，`versionCode` 为 `43`。没有新增依赖、权限或构建工具。
