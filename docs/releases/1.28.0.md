# Token Monitor Android 1.28.0

- **适配主线 v0.98.0 与跨设备固定统计区间：**
  - 新增从主线逐字节同步的 `src/shared/fixedPeriodRanges.js`（保持浏览器全局 `TokenMonitorFixedPeriodRanges` 与 CommonJS 双导出），并通过 `ConnectionSpec` 只读白名单端点 `GET /api/fixed-ranges`（按设备修订号读取索引与分页明细，周一作为 `week` 同步锚点）与 `GET /api/devices`（仅读取已开启历史同步设备的 `history.daily` 汇总回退），完整支持「昨日」「本周」「近 7 天」「近 30 天」四类跨设备固定统计区间。
  - 在「更多范围」菜单与「设置 → 显示偏好」中新增统计周期按钮自定义能力，支持将 3–6 个常用范围固定至顶部周期栏、调整排序并一键恢复默认，由 `DisplayPrefs` 安全校验并持久化。
  - 保留固定统计区间内已删除或已归档的会话条目状态展示与 T3 Code Antigravity ACP 会话标识；无标题独立会话在列表回退显示项目名称并保留可见会话 ID，详情页主标题保持「工具 · 模型」。
- **总览体验与多账号兼容增强：**
  - 总览「实时会话速览」新增「详细 / 紧凑」展示密度切换、单段简写活跃时长与确认来源设备标识；「核心额度速览」完整呈现账户内全部可见配额窗口与重置倒计时。
  - 核验第三方多账号混合大小写键名的自定义排序与命名展示兼容性。
- **回归测试与验证：**
  - 新增 `tests/android/upstream98.test.js`，扩充 `ConnectionSpecChecks.java`、`nativeState.test.js` 与 `StartupTest.java` 仪器测试；全部通过 Node 单元测试、纯 Java 17 规则校验、React TypeScript / Vite 构建、Android Lint 与 Android 15 模拟器仪器测试。

本版沿用原正式签名，`versionCode` 为 `50`。没有新增依赖、权限或构建工具。
