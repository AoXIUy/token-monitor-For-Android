# Token Monitor Android 1.17.0

- 适配主线 `v0.93.0`：
  - **多 Hub 凭据管理**：`ConnectionStore` 使用 Android Keystore AES-GCM 加密保存多个 Hub 配置，支持在设置页一键切换、新增、重命名或删除 Hub，断开当前连接时保留已保存列表；网页侧不读取已保存密钥，更改目标地址或协议时仍要求重新输入密钥，并兼容迁移旧版单连接存储。
  - **Qoder / Qoder CN 展示偏好**：同步共享 `clientCatalog.js` 的 `qodercn` 客户端标识；默认将 Qoder 与 Qoder CN 合并为 `Qoder`，可在设置中切换「分开显示 Qoder 与 Qoder CN」，同步生效于总览分布与桌面微件。
  - **本地额度历史迁移**：按观测时间统一合并兼容来源的额度变化（忽略 `< 1pp` 的微小抖动与延后截止时间），不再在正常/兼容来源切换时把正常曲线标成冲突基线，并在本地 SQLite（数据库版本升级至 2）中自动迁移已校验账户别名历史（保持 OpenCode 密钥隔离）。

本版沿用原正式签名，`versionCode` 为 `34`。没有新增依赖、权限或构建工具。
