# Token Monitor Android 1.22.0

- 同步适配 [Javis603/token-monitor v0.95.0](https://github.com/Javis603/token-monitor/releases/tag/v0.95.0)（`4a36ad4f`）并全面升级 Android 界面与原生桌面微件视觉体验：
  - **新增客户端适配（Junie / OpenCodeReview）：** 增量同步 `src/shared/clientCatalog.js`（新增 `junie` 与 `opencodereview`），扩展原生桌面微件白名单（`WidgetLayoutPolicy`）与前端客户端色调映射（`ui/src/utils/formatters.ts`），同时确认 Grok Build、WorkBuddy、CatPaw 会话上下文窗口用量与剩余容量可在详情页正常展示。
  - **界面视觉与统一基础组件重设计：** 新增共享交互基础组件库（`ui/src/components/ui/Primitives.tsx`），统一总览、会话、会话详情/在线对话/实时速率、额度与历史趋势、设备、报告与阅读窗口、审批提醒、设置及更新弹窗的层次、开关、状态文案（`limitStatusLabel`）与扩展工具配色。
  - **深色系统栏与安全区优化：** 升级原生主题至深色 `Theme.Material.NoActionBar`（`styles.xml` / `values-v27/styles.xml`）并通过 `WindowInsetsController` 保持状态栏与导航栏图标在深色背景下清晰可读，优化资源不可用时的回退界面排版。
  - **原生桌面微件与 Android 12+ 预览升级：** 重绘全系列微件布局（今日用量、紧凑 2×1/2×2、周期对比、额度卡片），补充 `drawable-v31/` 适配样式与 `preview_widget_*.xml` 独立微件选择器预览，并在 `UsageWidgetProvider` 中细化未连接/等待状态的文字配色与进度条精度。
  - **测试与只读边界：** 新增 `tests/android/upstream95.test.js` 并扩充 `WidgetPolicyChecks.java`，保持只读 `GET` 接口、Bearer 鉴权与现有权限边界不变。

本版沿用原正式签名，`versionCode` 为 `40`。没有新增依赖、权限或构建工具。
