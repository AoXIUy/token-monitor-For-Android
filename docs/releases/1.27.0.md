# Token Monitor Android 1.27.0

- **新增 6 套内置主题与跟随系统外观（多主题系统）：**
  - 内置 6 套高对比度语义主题——**深空遥测**（Obsidian）、**晴空纸韵**（Daylight）、**琥珀终端**（Amber）、**翠影幽境**（Emerald）、**暮霞紫境**（Nebula）与**冰川薄雾**（Frost），并支持「跟随系统外观」（Auto，自动在深空遥测与晴空纸韵间切换）。
  - 在设置页顶部新增「外观与主题」工作室卡片（`ThemeStudioCard`），提供 2×3 实时线框微缩预览与一键切换；全面重构 `ui/src/index.css` 及全部页面、弹窗、图表与 Markdown 渲染器的 `--tm-*` 语义色板，兼容浅色 / 深色双极性对比度与 Android WebView 弹窗 `::backdrop`。
  - 原生层新增纯 Java `ThemePolicy` 并扩展 `DisplayPrefs` 持久化主题配置（兼容旧版配置安全回退默认主题），`MainActivity` 在冷启动创建视图与运行期切换时同步窗口、视区、WebView 背景色及系统状态栏 / 导航栏配色与图标明暗，并在 React 首次挂载前写入文档主题属性，消除启动闪烁。
- **全面界面视觉升级与图表体验优化：**
  - 升级顶部导航与底部 Material 3 胶囊导航栏，统一全站触控目标与排版层级，保持 360px 窄屏无横向溢出与无障碍语义一致。
  - 优化历史趋势图（`HistoryChart`）与额度历史图（`QuotaHistoryPreview`）：独立左外侧 Y 轴标签与固定纵横比避免文字拉伸和曲线遮挡，分离真实峰值与刻度上限，优化折线 / 柱状模式切换与单日选中交互。
  - 升级报告阅读器弹窗（新增顶部阅读进度条）、Markdown 表格与代码块窄屏换行排版，以及会话实时速率图表的独立坐标留白。
- **全量审计缺陷修复与边界加固：**
  - 修复键盘收起或切换页面后底部导航栏残留隐藏的问题（由原生 `MainActivity` 实时检测输入法可见性并同步至前端），以及应用更新弹窗点击内边距意外关闭的问题。
  - 修复连接设置页编辑已保存 Hub 时的配置与自定义 CA 证书误清除风险，以及选择证书后 Activity 重建导致草稿丢失的问题；将 `DisplayPrefs` 保存改为非阻塞持久化并避免连续切换主题闪烁。
  - 修复会话页搜索时误清空工具筛选、分页剩余条数计算、在线对话搜索时分组无法收起与后台过期状态误清空已加载正文，以及审批提醒折叠后无法恢复的问题。
  - 修复额度页「正常」KPI 筛选、AG 账号池和报告数据重复键去重、额度历史非原生预览无限加载，以及报告耗时和 Markdown 列表嵌套表格解析等边界缺陷。
- **回归测试与验证：**
  - 新增 `ThemePolicyChecks.java`、`tests/android/themeSystem.test.js` 与 `StartupTest.java` 主题切换与冷启动持久化仪器测试，并扩充状态、Markdown、会话、报告与 AG 账号池单元测试；全部通过 Node 单元测试、纯 Java 17 规则校验、React TypeScript / Vite 构建、Android Lint 与 Android 15 模拟器仪器测试。

本版沿用原正式签名，`versionCode` 为 `49`。没有新增依赖、权限或构建工具。
