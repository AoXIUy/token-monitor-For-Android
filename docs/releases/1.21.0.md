# Token Monitor Android 1.21.0

- 同步并只读适配 [Javis603/token-monitor v0.94.0](https://github.com/Javis603/token-monitor/releases/tag/v0.94.0)（`5888563c`）：
  - **跨设备额度账号呈现只读同步（`limitAccountPresentation`）：** 在 `stats.syncSettingsRevisions.limitAccountPresentation` 变更时自动通过只读 `GET /api/sync/settings/limitAccountPresentation` 同步桌面端配置的按服务商账号排序与自定义名称，并在账号标签上应用显式命名与空名回退；遵循只读边界，不向 Hub 写入设置变更。
  - **阿里云百炼（Alibaba Token Plan）多地域适配：** 新增 `limitSelectionKey`（隔离中国站 / 国际站 `region`）及区域/套餐标识展示（`中国站 · 团队版` / `国际站 · 团队版` / `中国站 · 个人版` / `国际站 · 个人版`），防止多地域账户命名或排序互相覆盖。
  - **桌面微件服务商白名单扩展：** `WidgetLayoutPolicy` 新增支持 `alibaba`、`zai`、`zaiteam`、`kimi`、`cline`、`factory`、`grok`、`zed`、`commandcode`、`devin`、`volcengine`、`trae`、`stepfun`、`notion`、`typesafe`、`thirdparty`，确保多服务商额度可固定至桌面卡片。
  - **总览每日趋势精确 Token 展示开关：** 在设置与原生偏好（`DisplayPrefs.exactTrendTokens`）中新增「精确趋势 Token 数」开关，开启后在总览趋势卡片及按日选中摘要直接展示千分位精确数值，并保持实时轮询与原生状态持久化一致。
  - **共享计算与界面细节对齐：** 同步 `src/shared/sessionLive.js`（新增 `sessionWithActivity` 可选 `now` 参数），补齐 `windows[].productId` 字段类型与窄屏下会话上下文进度条对齐，并扩充 Node 展示单测、`ConnectionSpec` / `WidgetLayoutPolicy` 检查及 `StartupTest` / `UsageWidgetTest` 仪器测试。

本版沿用原正式签名，`versionCode` 为 `39`。没有新增依赖、权限或构建工具。
