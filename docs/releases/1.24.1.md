# Token Monitor Android 1.24.1

- **Antigravity 账号池（AG 账号池）UI 改版：**
  - 对齐桌面端高密度深色玻璃卡片布局，采用响应式多列卡片网格（手机单列、平板 2~3 列），激活账号采用天蓝色边框与高亮邮箱，单行截断邮箱并支持触摸友好的“复制邮箱”与内联状态反馈。
  - 优化卡片元信息行，统一展示本地化客户端槽位（经典款 / IDE / AGY / ACP）、异常状态徽章、渐变层级徽章（`◆ ULTRA` / `◆ PRO` / `FREE`）、独立指纹标识、模型能力标签与 `YYYY/MM/DD HH:mm` 更新时间。
  - 配额区域改为 2 列双栏 `3px` 细进度条网格，支持保留并解析快照中的 `quota.groups`（5h / 周配额及整行专属池），并在仅含 `models` 时自动降级汇总；保留只读约束与底部可展开模型详情列表。
  - 在 `AG 账号池` 子页隐藏无关的全局设备筛选栏，并在平板宽屏断点下适当放宽容器宽度，提升展示密度。

本版沿用原正式签名，`versionCode` 为 `44`。没有新增依赖、权限或构建工具。
