# Token Monitor Android 1.26.1

- **修复 AG 账号池多主机切换与刷新链路：**
  - 为非全宽 `SegmentedControl` 增加横向滚动边界保护，并将 AG 账号池主机切换器升级为受控横向滚动胶囊轨道（带左右渐变指示、仅横向自动居中与同名主机去重标识）；3 台及以上主机新增「切换主机」底部弹窗选择器并接入 Android 返回键关闭。
  - 修复不同设备间存在相同 `account.id` 时展开/复制状态串用问题；修复顶栏刷新按钮在 AG 账号池页未刷新 `/api/antigravity-manager` 快照的问题，并将 `#quota-tabs` 固定在筛选栏上方消除切换高度跳动。
- **升级「额度与订阅」三标签页展示与交互：**
  - AG 账号池升级为 `glass-hero` 遥测摘要面板，新增 5 格可点击 KPI 统计条、当前客户端激活槽位速览、高配额优先排序、一键重置筛选、清晰的 3 层配额网格（区分 Gemini / Claude 图标色与 `5h` / 周窗口标签）及展开模型进度条。
  - 账户额度页新增健康分布比例条、4 格可点击 KPI 面板与最近重置时间提示，优化筛选排序栏与服务商额度卡片层级（严格保持原有读数口径与无障碍契约）。
  - 共享订阅页按原币种分栏汇总月度订阅与累计预存（不跨币种换算），新增最近续费提示、类型筛选与搜索以及续费紧急度配色。
- **补充回归测试与验证：**
  - 扩充 `tests/android/ag-manager-state.test.js` 单元测试与 `StartupTest.java` 多主机横滑边界、弹窗切换、返回键关闭、状态隔离与顶栏刷新仪器回归测试，通过 Node 测试、Java 规则校验、Android Lint 与 Android 15 模拟器 77 项仪器测试。

本版沿用原正式签名，`versionCode` 为 `48`。没有新增依赖、权限或构建工具。
