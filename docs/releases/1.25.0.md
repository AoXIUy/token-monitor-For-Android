# Token Monitor Android 1.25.0

- **新增按连接隔离的自定义 CA / 自签名证书导入：**
  - 支持在 HTTPS Hub 连接设置中通过系统文件选择器（SAF `ACTION_OPEN_DOCUMENT`）或直接粘贴导入 `.pem` / `.crt` / `.der` 格式的 X.509 证书（单文件上限 24 KiB，最多 4 张证书链），自动拒绝包含私钥块（`PRIVATE KEY`）、RSA < 2048 位 / EC < 256 位弱密钥或不在有效期内的证书。
  - 证书通过 Android Keystore AES-256-GCM 与连接配置一同加密持久化；WebView 仅接收短期草稿令牌与脱敏摘要（SHA-256 指纹、Subject、Issuer、有效期），不向网页、微件或日志暴露原始 PEM 与 Hub secret。
  - 编辑已保存连接时，新增、替换或清除自定义 CA 均视为信任边界变更，强制要求重新输入 Hub secret；本地额度历史（`LimitsHistoryStore`）保持原有连接指纹连续性。
- **TLS 1.2+ 传输加固与网络安全配置：**
  - `HubClient` 按连接绑定独立的 `SSLSocketFactory`（CA 证书走标准 PKIX 链校验，直签 `CA:FALSE` 自签名叶证书仅允许精确 DER 指纹匹配且不提升为 CA 信任锚），通过 `Tls12PlusSocketFactory` 强制仅启用 `TLSv1.3` / `TLSv1.2`，严格保持系统默认 `HostnameVerifier` 域名 / IP SAN 校验，且不污染全局默认 SSL 工厂。
  - 新增 `network_security_config.xml` 移除全局明文许可属性，将 GitHub 应用内更新域名与 `appassets.androidplatform.net` 本地资源源锁定为仅 HTTPS + 系统证书；开启公网 / 非局域网明文 HTTP 时在设置页展示显式安全警告。
- **补充便携测试与 Android 15 模拟器仪器测试：**
  - 新增 `CertificateTrustPolicyChecks.java` 纯 Java 17 校验，扩充 `ConnectionSpecChecks.java`、`nativeState.test.js`、`ConnectionStoreTest.java`，并新增 `HubTlsInstrumentationTest.java` 在真机/模拟器回环 `SSLServerSocket` 上覆盖自定义 CA、自签名叶证书、错误 CA / 错误 SAN 拒绝及 WebView 端到端 TLS 连接。

本版沿用原正式签名，`versionCode` 为 `46`。没有新增依赖、权限或构建工具。
