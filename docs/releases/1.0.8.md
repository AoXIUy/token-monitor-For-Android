新增 GitHub Release 自动检查更新，应用版本为 **1.0.8 / versionCode 9**。

- 启动或回到前台时自动检查本仓库最新正式版，检查间隔至少 12 小时，可在「连接 → 软件更新」中关闭。
- 支持手动检查、查看当前安装版本和更新说明；发现新版本时显示提示，可选择稍后更新。
- 更新检查独立于 Hub，缓存上次结果，网络失败时保留旧结果和检查时间；进入后台取消请求。
- 仅接受固定仓库正式 Release 的对应版本 APK。点击下载后由系统浏览器处理，安装时需要确认。
- 修正设置页固定显示旧版本号的问题，改为读取实际安装版本。

Android 8.0+，沿用原有正式签名，同签名旧版可覆盖升级。首次使用更新检查功能，需要安装本版；之后可通过软件更新入口发现更高版本。
