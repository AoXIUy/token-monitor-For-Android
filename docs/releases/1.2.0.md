新增多主题多尺寸桌面微件与界面体验升级，应用版本为 **1.2.0 / versionCode 12**。

- 新增四类原生桌面微件（`今日用量`、`紧凑速览`、`多周期总览`、`额度监控`），支持 `2×1` 横条、`2×2` 方卡、`4×2` 标准与 `4×3` 展开布局，在 Android 12+ 使用 `SizeF` 响应式映射并在 Android 8.0–11 按尺寸断点自动切换。
- 丰富桌面微件有界展示数据：支持今日/本月/累计三周期对比、今日输入与输出拆解、缓存进度条、近 7 日总量与单日峰值、Top 3 主要工具分布，以及账户健康计数与高占用配额窗口进度条预警。
- 在「连接」页新增桌面微件卡片实时预览画廊，可直接用当前 Hub 数据切换查看 4 类卡片在不同尺寸下的效果与添加说明。
- 优化前端各页面可访问性与交互细节：补齐 WebView 剪贴板复制降级、44px 触控热区、ARIA 语义状态、单设备筛选快捷重置、工具筛选横向滚动渐隐提示及自定义聚焦环。
- 保持微件有界日期摘要与隐私边界，不持久化会话标题、设备名、账户邮箱或 Hub 凭据。

Android 8.0+，沿用原有正式签名，同签名旧版可覆盖升级。已安装 1.0.8 及以上版本的用户可从「连接 → 软件更新」检查本次更新。
