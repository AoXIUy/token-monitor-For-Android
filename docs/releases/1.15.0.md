# Token Monitor Android 1.15.0

- 新增可选的 Codex / Antigravity **只读审批提醒**功能：在设置卡片中默认关闭，需要搭配本分支 0.93.0 的桌面端 / Agent 与 Node Hub（需同时开启电脑端与 Hub 端开关；Cloudflare Worker 不提供此接口）。
- 开启后沿用现有 5 秒 GET 轮询与前台刷新读取 `GET /api/approval-alerts`（客户端保持 100% GET 只读，不发起写入且不阻塞电脑端弹窗），对每条新提醒 ID 通过 `ApprovalStore` 去重后在 `session-approvals` 高优先级通知通道发送一次性只读通知（锁屏公开视图隐藏敏感细节，无允许/拒绝按钮）。
- 「总览」页新增只读待确认提醒横幅与卡片，展示设备、来源工具、项目名、工具/命令及相对时间，提示「请前往电脑端确认」，支持在本地「收起」单条提醒，并在停用开关或断开 Hub 时清理提醒快照与通知。

本版本沿用原正式签名，versionCode 为 28。没有新增 npm/Gradle 依赖或系统权限（新增只读接口路径 `GET /api/approval-alerts`）。正式发布需通过便携校验、Android lint、模拟器仪器测试及 APK 身份、证书和 ZIP 对齐校验。
