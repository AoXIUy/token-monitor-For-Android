# Token Monitor Android 1.13.1

- 升级「额度与订阅」页面：新增实时额度遥测摘要头、搜索栏、状态筛选（全部 / 有采集 / 预警 / 异常）、按压力/更新时间排序，以及「已用优先 / 剩余优先」显示口径切换。
- 支持隐藏无采集历史的工具：默认自动收纳未配置/停用/从未读到有效数值的工具卡片，支持手动隐藏单个工具并持久化本地偏好，底部提供一键恢复与管理入口；同时升级「额度历史」SVG 渐变趋势图与 14 天净变化柱图，并保持图表 `<svg>` 语义选择器稳定。
- 对齐桌面端 `v0.92.0` 额度展示口径：补齐全部 35+ Provider 友好名称与品牌色调、同步 Cursor `Weekly` / `Monthly` 周期标签与 `windowText` 全量窗口明细（Kiro / Zed / GLM / Kimi）、支持 DeepSeek Search/Fetch 消费、第三方 API 现金周期以及 14 种货币符号和 `KRW` / `JPY` 零小数格式。

本版本沿用原正式签名，versionCode 为 25。没有新增 npm/Gradle 依赖、Hub 网络接口或系统权限；同步引入上游可移植计算模块 `currency.js` 并更新 `windowLabels.js`。正式发布需通过便携校验、Android lint、模拟器仪器测试及 APK 身份、证书和 ZIP 对齐校验。
