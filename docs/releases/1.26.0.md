# Token Monitor Android 1.26.0

- **同步适配主线 v0.96.1 + v0.97.0（`9d745c10`）：**
  - 在权威展示模型 `model.js` 中统一会话排序逻辑（支持按最近活动、Token 用量、费用排序并对齐主线 `tokens → recent → cost → key` 并列回退，包含子代理家族合并用量），切换周期或设备时保留当前排序选择。
  - 支持新会话待上报状态（`tokenDataUnavailable: true`）：在会话列表、子代理成员行与会话详情页中先展示 `0` Token 与 `$0.00`，待首笔用量数据到达后立即替换为实际读数；非待定的缺失字段仍保持显示 `—`。
  - 核验并覆盖 Antigravity 关闭本机额度检测后的纯 OAuth 账号展示、匿名本机 RPC 恢复移除后的身份一致性，以及 Tokscale 4.23.1 的 Zed Agent 用量、Pi 会话名称清除回退与 Kimi Code 响应速度展示。
- **共享模块校验与回归测试：**
  - 更新 `docs/upstream-files.json` 至主线 `v0.97.0`（`9d745c106ac5030045dade55c0d1aea279cdcfd7`），12 个受管 `src/shared/` 共享计算模块 SHA-256 与主线逐字节一致。
  - 新增 `tests/android/upstream97.test.js` 覆盖模型排序、待上报会话零值占位、Antigravity 纯 OAuth / 匿名恢复与 Zed / Pi / Kimi 消费契约，并通过 Node、Java 校验、Android Lint 与 Android 15 模拟器 76 项仪器测试。

本版沿用原正式签名，`versionCode` 为 `47`。没有新增依赖、权限或构建工具。
