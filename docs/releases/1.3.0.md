新增应用内更新流程，并修复审计发现的数据展示问题，应用版本为 **1.3.0 / versionCode 14**。

- 启动应用时检查最新正式版，发现新版本会弹窗展示更新说明，可下载或稍后处理。保留自动检查开关，普通前后台切换按 12 小时间隔检查，也可在「连接 → 软件更新」手动检查。
- 在应用内下载 APK，显示进度，支持取消、失败重试，以及恢复已完成的下载。下载后核对发布元数据、文件大小、SHA-256、包名、版本代码和原有正式签名；校验失败会阻止安装。
- 校验通过后引导系统来源安装授权与安装确认。安装交接前再次校验，仅向系统安装器提供已校验 APK 的临时只读访问，不需要存储权限。
- 修复微件较晚返回的请求可能覆盖新错误状态的问题；历史摘要按实际日历日期统计近 7 日小计和近 14 日峰值，缺失数据不再混入较早记录。
- 统一零余额与额度占用的预警口径；修复「已结束」筛选混入未知或空闲会话，以及会话详情忽略设备数据有效期的问题。
- 增加下载、校验、取消、恢复、弹窗、微件和会话筛选的回归检查，并提供代码审计、修复记录与应用内更新说明。

Android 8.0+，沿用原有正式签名，同签名旧版可覆盖升级。旧版可从「连接 → 软件更新」检查并下载本次更新；新的应用内下载安装流程从本版开始提供。系统来源授权、安装确认和覆盖升级仍由 Android 及用户控制。
